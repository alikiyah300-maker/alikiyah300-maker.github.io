CloudVault Privacy Policy

Last updated: November 13, 2026

This page describes privacy considerations for the CloudVault informational website and the project's current software components. The actual information handled depends on which component and integrations a person chooses to use.

1. Informational Website

This website is a static project-information website. It does not provide user accounts, contact forms, or file-upload features. It is hosted by GitHub Pages. GitHub may process technical information such as request and security logs when visitors access the website. Please consult GitHub's privacy statement for information about its processing.

2. Current Mini App

The current CloudVault Mini App frontend uses a MockEngine for demonstration and interface testing. In this configuration, it does not perform real cloud uploads or cloud-side file modifications.

3. Optional Desktop and Cloud Integrations

Separate desktop components of the CloudVault project may be configured to interact with third-party cloud storage services, including Google Drive, using tools such as Rclone. These optional integrations are distinct from this static website and from the current MockEngine-based Mini App.

When a user enables and uses such an integration, files and related information may be transmitted to the selected cloud provider. The information processed depends on the user's actions, software configuration, requested permissions, and the provider's service.

4. Google Account Authorization

If a user chooses to connect a Google account through an OAuth-based integration, Google presents an authorization flow describing the access requested. The integration can access Google user data only within the permissions granted and as implemented by the relevant software component.

Google account data and Google Drive content are subject to Google's terms and privacy policies. Users can review and revoke third-party account access through their Google Account security settings.

5. Local Configuration and Security

Desktop integrations may store configuration and authentication material on the user's device as required for their operation. Users should protect their devices and application configuration files, restrict access to them, and avoid sharing credentials or authorization tokens.

No method of electronic storage or transmission is completely secure. Security practices may differ between project components and third-party services.

6. Third-Party Services

Depending on the component being used, third-party services may include GitHub, Google, and Rclone. Those services operate under their own terms and privacy policies. Users should review the applicable policies before using those services.

7. Children's Privacy

The CloudVault website and project are not directed specifically to children. The website does not provide account registration or a form for submitting personal information.

8. Changes to This Policy

This policy may be updated as the project and its features evolve. The revision date at the top of this page will be changed when an update is published.

9. Contact

This page currently does not publish a dedicated privacy contact address. A contact method should be added here before this policy is used as the formal privacy-policy URL for a public OAuth application.
